# Pet Manager 🐾

**Pet Manager** — это удобное приложение для учёта домашних животных, созданное для ответственных владельцев. Забудьте о бумажных записях! Ведите цифровые карточки питомцев, контролируйте график прививок и храните историю визитов к ветеринару в одном месте.

## Возможности (Features) ✨

*   **Карточки питомцев:** Создавайте подробные профили для каждого животного.
*   **Календарь событий:** Умный календарь показывает все предстоящие визиты к врачу и плановые прививки.
*   **Ветеринарный учёт:** Фиксируйте историю болезней, осмотров и причин обращений в клинику.
*   **Управление прививками:** Добавляйте информацию о сделанных вакцинах, и приложение автоматически напомнит, когда подойдёт время ревакцинации.
*   **Фото питомца:** Загружайте и храните фотографии ваших любимцев прямо в их карточках.

## Структура данных (Data Entities) 📂

Проект построен на трёх основных сущностях:

### 1. Питомец (Pet)
Хранит основную информацию о животном:
*   **Кличка**
*   **Вид** (собака, кошка, попугай и т.д.)
*   **Порода**
*   **Дата рождения**
*   **Фото** (опционально)

### 2. Прививка (Vaccination)
Учёт вакцинации:
*   **Название** вакцины
*   **Дата** проведения
*   **Следующая дата** (дата ревакцинации, используется для напоминаний)

### 3. Визит (Visit)
История посещений ветеринарной клиники:
*   **Дата** посещения
*   **Причина** (плановый осмотр, болезнь, травма)
*   **Заметки** врача или владельца (рекомендации, назначения)

## Роли пользователей (Roles) 👤

*   **Владелец:** Основной и единственный пользователь. Может добавлять/редактировать информацию о своих питомцах, просматривать календарь и управлять записями.
